# Known in Cursor

Shared memory for teams. Give every AI agent a foundation of organizational understanding. Known preserves your company's knowledge, decisions, and history so agents can work with context from the start.

[Add Known to Cursor](https://cursor.com/en/install-mcp?name=known&config=eyJ1cmwiOiJodHRwczovL2FwaS5rbm93bi5pbmZvL21jcCJ9)

Or open `cursor://anysphere.cursor-deeplink/mcp/install?name=known&config=eyJ1cmwiOiJodHRwczovL2FwaS5rbm93bi5pbmZvL21jcCJ9`, or add it by hand to `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "known": {
      "url": "https://api.known.info/mcp"
    }
  }
}
```

Cursor opens Known in your browser to sign in; there is no key. More: https://known.info/setup.md
